# AI & Data Strategy News — podcast

Auto-generated personal podcast feed for a daily (short) and weekly (longer) AI &
data-strategy news update, produced by the `claude-mcp-starter` pipeline.

- **Feed URL** (add this to your podcast app): `https://raw.githubusercontent.com/meskensj/ai-news-podcast/main/feed.xml`
- Episodes (MP3) are published as **Releases** of this repo.
- `episodes.json` is the index; `feed.xml` is generated from it.

This repo is public so the audio + feed are reachable by podcast apps, but the feed
URL is unlisted (not submitted to any directory).
